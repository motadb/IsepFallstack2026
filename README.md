# DevScope Academy @ ISEP

Apresentação interativa em forma de grafo: cada nó é um tópico.

- **Apresentar:** abrir `index.html` no browser (ficheiro único, funciona offline).
- **Navegar:** `→` / `←` (ou clicker), clicar num nó, `Esc` para o mapa, `F` para ecrã inteiro, `L` para modo claro/escuro, `T` (ou botão PT/EN) para mudar de idioma (arranca sempre em EN/escuro; `?lang=pt` e `?light` no endereço forçam PT / claro). O QR do último slide aponta para devscope.net/careers/curricular-internship.
- **Editar conteúdo:** `src/content.js` (imagens em `assets/`), depois `node build.mjs`.
